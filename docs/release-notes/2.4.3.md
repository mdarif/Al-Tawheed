# Kitab at-Tawheed 2.4.3: release notes

2.4.3 supersedes 2.4.2, which reached only Play's internal track and was never
promoted. Production users move straight from 2.4.1 to 2.4.3, so these notes
describe everything since 2.4.1. The only change after 2.4.2 is the first-launch
fix under Reliability (a bounded wait for the start-up network fetches). The
release workflow uses the "GitHub Release notes" section below as the GitHub
Release body and adds its own "Device verification" line after it.

## Play "What's new" (under 500 characters)

```
• Search lectures and classes in English, Urdu, Roman Urdu or Arabic.
• Library: Bookmarks and Downloads in one place.
• Book and Study share one Read tab.
• Text-size slider in Settings and the reader's Aa button.
• Downloads continue after you close the app or lose signal.
• Your reading position is kept per edition.
• Safer switching between Urdu and Arabic editions.
• Faster first launch on slow or unreliable networks.
• Layout fixes for large text and the mini-player.
```

Length: 477 characters, 495 bytes. Play's limit is 500 bytes (a bullet takes 3).
The release workflow uploads this block as it is, for every locale, and never
shortens it: `prepare` checks it on every run, a dry run included, and fails the
release if it is over the limit (`tool/release_git.py play-notes`).

## GitHub Release notes (longer)

### Find things faster

- Search lectures and classes in English, Urdu, Roman Urdu and Arabic. Numbers
  match across numeral styles, so "12", "۱۲" and "١٢" find the same class or lecture.
- A class grid on the search screen takes you to any class in two taps. Tapping a
  class returns you to Lectures, scrolled to that class.

### Library and Read

- Library has one title with Bookmarks and Downloads tabs. The same screen opens
  from every entry point.
- Book and Study share one Read tab, with a tab for each. Study completion returns
  you to Read › Study.
- The ⋮ overflow menu is gone from Read.

### Settings and reading

- Settings has a Reading section with a text-size slider. The reader's Aa button
  changes the same setting.
- Settings has About and Our other apps. On Android, Our other apps lists Al Quran
  Reader and As-Sunnah Search.
- Mistake reports include the edition, chapter and app version in the email subject,
  and their links open with correct line breaks.

### Downloads and playback

- A failed download can be removed, not only retried.
- A working download is no longer discarded because the catalogue lists a
  different file size.
- The Lectures and Downloads lists, and the last Study class card, are no longer hidden
  behind the mini-player or the bottom bar.

### Reliability

- First launch on a slow or unreliable network no longer leaves a blank
  screen: if the server does not answer within about 10 seconds, the app starts
  with its built-in defaults and fetches the latest settings in the background.
- Downloads are restart-safe: queued and in-progress downloads continue after
  the app is closed or the connection drops, and a partial file is never played.
- Your reading position and "Continue reading" are kept separately for each
  edition, and a stale chapter link shows a recovery screen.
- Switching between the Urdu and Arabic editions is serialized and explained,
  and an edition that is no longer available shows a recovery screen instead of
  silently switching you to another one.
- Notification permission is asked when you first download, with an
  explanation, instead of at startup.
- Playback recovers more reliably from interruptions and errors.

### Fixes

- Text that overflowed at default and larger sizes is fixed in all four languages.
- The light/dark theme change is smoother.
- The offline banner's link is quieter.
